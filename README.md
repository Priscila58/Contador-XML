# 📊 Analisador de XMLs Fiscais

> Uma ferramenta web para leitura e contabilidade automática de arquivos XML (NFe e CFe).

## 🔗 Link do Projeto
[Clique aqui para acessar o sistema online](https://priscila58.github.io/Contador-XML/)

## 💻 Sobre o Projeto
Este projeto foi desenvolvido para simplificar a conferência de notas fiscais. Ao invés de abrir arquivo por arquivo e somar na calculadora, o sistema lê múltiplos arquivos XML simultaneamente e gera um relatório consolidado.

**Funcionalidades:**
- Leitura de múltiplos arquivos .xml de uma vez.
- Identificação automática da Loja/CNPJ.
- Cálculo do valor total das vendas do dia.
- Interface limpa e responsiva.
- **Segurança:** Todo o processamento é feito no navegador (Client-Side), nenhum dado é enviado para servidores externos.

## 🛠 Tecnologias Utilizadas
- **HTML5** (Estrutura)
- **Tailwind CSS** (Estilização Moderna)
- **JavaScript ES6+** (Lógica de leitura de arquivos e manipulação do DOM)
- **Git & GitHub** (Versionamento e Hospedagem)
